
# Frontend Projects

This directory contains frontend web applications built to explore modern user interface development, component architecture, application state, navigation, and interactive experiences.

These projects demonstrate my experience working with React, JavaScript, CSS, and modern frontend tooling.

## Projects

### Game Vault

[Explore Game Vault](game-vault/)

A gaming platform-inspired frontend prototype featuring a game library, store interface, community pages, searching, and game details.

**Technologies:** React, Vite, React Router, JavaScript, CSS.

### Relic Forge

[Explore Relic Forge](relic-forge/)

A fantasy RPG-inspired frontend application featuring character management, inventory, equipment, skill progression, quests, a world map, and an in-game codex.

**Technologies:** React, Vite, JavaScript, CSS, Lucide React.

## Areas of Focus

- Reusable React components
- Client-side routing
- Interactive application interfaces
- State management
- Data-driven rendering
- Responsive layouts
- Component-based architecture
- UI and UX experimentation
- Browser storage and local application state

## Project Scope

The applications in this category are primarily frontend-focused prototypes.

They are intended to demonstrate frontend engineering skills rather than operate as fully deployed commercial products.

For applications with backend services and databases, see [Full-Stack Projects](../fullstack-projects/).

## Getting Started

Each project has its own dependencies, configuration, and development instructions.

For React/Vite projects, the typical development workflow is:

```bash
npm install
npm run dev
```

Consult the individual README before running a specific project.
