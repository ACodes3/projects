
# DevOps Projects

This directory contains infrastructure, deployment, and automation projects developed during my software engineering studies and independent programming work.

The projects explore how applications are configured, deployed, containerized, and operated in reproducible environments.

## Areas of Focus

- Virtual machine provisioning
- Containerization
- Container orchestration
- Infrastructure configuration
- Reproducible development environments
- Application deployment
- Networking and service configuration
- Development and operations workflows

## Technologies

Technologies explored include:

- Vagrant
- Docker
- Kubernetes
- Linux
- YAML
- Shell scripting

## University DevOps Project

One of my university projects involved working with Vagrant, Docker, and Kubernetes to understand infrastructure provisioning, container execution, and orchestration.

The project serves as a practical demonstration of infrastructure and DevOps concepts alongside my frontend, backend, and full-stack development experience.

Refer to the individual project folders for the exact configuration, architecture, and execution instructions.

## Notes

Infrastructure projects may require virtualization support, Docker, or other system dependencies.

Always review each project's configuration and README before executing provisioning or deployment commands.
