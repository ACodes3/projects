# Database Projects

Database-centered work, including relational schema design, SQL, queries, constraints, and data-modeling exercises.

## Focus areas

- Table design and relationships.
- Keys, indexes, checks, and integrity constraints.
- SQL queries and data manipulation.
- Initialization, migrations, and seed scripts where provided.

## Using the projects

Each directory may target a different database engine. Read its own documentation and SQL files before executing anything. In particular, review scripts that contain `DROP`, `TRUNCATE`, `DELETE`, or resetting seed operations; they may replace existing data.

Use a development or test database, and never execute example seeds against valuable data without a backup. Database schemas and demonstration data are different from personal or production records.

## Repository organization

Database files embedded in full-stack applications may also be documented inside their respective project folders under [`fullstack-projects/`](../fullstack-projects/).
