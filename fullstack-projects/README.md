
# Full-Stack Projects

This directory contains applications developed using both frontend and backend technologies, including relational databases, APIs, and persistent application state.

These projects demonstrate my approach to designing and implementing applications across the entire software stack.

## Projects

### Demon Slayer Archive

[Explore Demon Slayer Archive](demon-slayer-archive/)

A Demon Slayer-inspired character and information archive combining a React frontend with an Express REST API and PostgreSQL database.

**Technical highlights:**
- React and Vite frontend
- Express REST API
- PostgreSQL persistence
- CRUD operations
- Zod validation
- Swagger/OpenAPI documentation
- Vitest and Supertest testing

### Crown of Winter

[Explore Crown of Winter](crown-of-winter/)

A multiplayer strategy-game prototype inspired by the world of Genshin Impact.

**Technical highlights:**
- React frontend and Express backend
- PostgreSQL database
- Session-based authentication
- World and character assignments
- Role-based authorization
- Interactive War Table
- Real-time Socket.IO synchronization
- Shared chat and private correspondence

The project is a technical prototype, not a completed commercial game.

### FORGE — Full-Stack Edition

[Explore FORGE Full-Stack](forge/)

A training and nutrition tracking application developed with React, Express, and PostgreSQL.

**Technical highlights:**
- React frontend
- Express REST API
- PostgreSQL relational data storage
- Workout tracking
- Exercise management
- Nutrition records
- Progress monitoring
- Dashboard functionality

The full-stack edition is distinct from the SQLite-based [FORGE Desktop application](../desktop/forge/).
