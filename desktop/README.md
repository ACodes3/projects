
# Desktop Applications

This directory contains desktop application projects developed as part of my software engineering portfolio.

My desktop development work focuses on integrating modern web technologies with native desktop application capabilities.

## Featured Project

### FORGE — Training & Nutrition Tracker

[Explore FORGE Desktop](forge/)

FORGE is an offline-first Windows fitness tracking application built with Electron, React, Express, and SQLite.

The application brings together workout management, nutrition tracking, exercise records, body-progress monitoring, and local data persistence.

### Technical Highlights

- Electron desktop application architecture
- React-based user interface
- Local Express REST API
- SQLite database integration
- Offline-first data storage
- Database initialization and backup/restore functionality
- Windows installer packaging with electron-builder

FORGE Desktop v1.0.0 has been packaged locally as a Windows application.

The public repository contains the application source code and packaging configuration, but does not distribute the installer executable.

## Technologies
